An illustrated one-page account of four consequential events on 19 November
2026. All illustrations were drawn for this entry. The front page groups
diplomacy, justice, climate and business in a 1024 × 1024 PNG.

```sh
MAKEFUN_OUTPUT_DIR=out python3.13 -P -s main.py
```

The Python entry emits the same PNG on each run using the standard library.
